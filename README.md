# Sameer Paykel Portfolio

Personal portfolio website for [spaykel.com](https://spaykel.com), built with React, Vite, JavaScript, and CSS.

## Development

Install dependencies:

```bash
npm install
```

Run locally:

```bash
npm run dev
```

Build for production:

```bash
npm run build
```

Preview the production build:

```bash
npm run preview
```

## Content

Most editable portfolio content lives in:

```text
src/data/portfolio.js
```

Static assets such as the resume PDF and images live in:

```text
public/
```

## Deployment

The site is configured for GitHub Pages with a custom domain. The `CNAME` file and `public/CNAME` preserve the `spaykel.com` setup.
